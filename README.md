# Drift - 3D Shopping E-Commerce Experience

A modern, immersive 3D fashion and shopping e-commerce web application built with **Next.js**, **Tailwind CSS**, **GSAP**, and **Lenis Smooth Scroll**.

![License](https://img.shields.io/badge/license-MIT-blue.svg)
![Next.js](https://img.shields.io/badge/Next.js-14-black)
![TailwindCSS](https://img.shields.io/badge/TailwindCSS-3.4-38B2AC)

---

## ✨ Features

- **Immersive 3D Experience**: Interactive dress/model presentations with dynamic visuals and video integration.
- **Smooth Animations**: Powered by GSAP and Lenis for fluid scrolling and micro-interactions.
- **Modern UI/UX**: Minimalist, luxury brand aesthetics with responsive layouts.
- **Curated Sections**:
  - Hero with video cutout & dynamic model showcase
  - Interactive Product Showcase
  - Popular Picks & Collections
  - Category Grid & Identity Showcase
  - Featured Products & New Arrivals
  - Customer Testimonials & Responsive Footer

---

## 🛠️ Tech Stack

- **Framework**: [Next.js 14](https://nextjs.org/) (App Router)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [GSAP](https://greensock.com/gsap/) & [Lenis](https://lenis.darkroom.engineering/)
- **Icons**: [Lucide React](https://lucide.dev/)

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/sd-coder07/3D-Shopping-Ecommerce.git
cd 3D-Shopping-Ecommerce
```

### 2. Install dependencies

```bash
npm install
```

### 3. Run development server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

---

## 📦 Build for Production

```bash
npm run build
npm run start
```
